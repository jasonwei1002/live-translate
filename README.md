# Subtle

macOS 菜单栏实时翻译字幕工具：捕捉**系统音频**（任意应用、网页、播放器），实时翻译，
以悬浮字幕显示在屏幕上。看英文直播、听外语播客、开跨语言会议时，字幕直接浮在画面上。

![macOS 14+](https://img.shields.io/badge/macOS-14%2B-blue) ![Swift 6](https://img.shields.io/badge/Swift-6-orange)

## 功能

- **系统音频捕捉**：基于 ScreenCaptureKit，无需虚拟声卡，任何 App 的声音都能翻译
- **实时同传**：豆包同声传译 2.0（火山引擎 AST），逐词流式输出
- **悬浮字幕**：仅显示当前翻译句——逐词生长、整句停留至下一句开始，无抖动；可拖拽定位
- **状态可见**：服务开启后显示「正在聆听…」占位，出错时错误直接显示在字幕条上
- **双语 / 仅译文**：源语言原文可选显示
- **三种字幕样式**：深色条 / 毛玻璃 / 描边，字号 16–72px，背景不透明度可调
- **语言支持**：中、英、日、韩、法、德、西、葡、俄、意等 20 种语言互译（源或目标至少一方为中文或英语；粤语、上海话可作为源语言）
- **省钱设计**：静音检测自动暂停发送（不消耗计费时长）；无声自动停止服务（默认 30 秒，可调）
- **内置自动更新**：从 GitHub Releases 检查并一键升级

## 安装

1. 从 [Releases](https://github.com/jasonwei1002/Subtle/releases/latest) 下载 `Subtle.dmg`，打开后将 Subtle 拖入「应用程序」。
2. **首次打开**：本应用未经 Apple 公证，系统会提示无法验证开发者——前往
   **系统设置 → 隐私与安全性**，在页面底部点击「**仍要打开**」（macOS 14 也可右键应用 → 打开）。
3. **屏幕录制权限**：首次开启翻译服务时，按提示在 系统设置 → 隐私与安全性 → 屏幕录制 中允许 Subtle
   （ScreenCaptureKit 捕捉系统音频需要此权限，应用不录制、不上传屏幕画面）。

## 快速开始

1. 在[火山引擎控制台](https://console.volcengine.com/speech/new/setting/)开通同声传译服务并创建 API Key；
2. 点击菜单栏的 Subtle 图标 → 设置…（⌘,）→ 翻译服务，填入 API Key，点「保存」，可用「测试连接」验证；
3. 选择语言方向（如 英语 → 中文），回到菜单栏面板打开开关；
4. 播放任意有声内容，字幕出现在屏幕下方，可拖到任意位置。

## 设置项

| 位置 | 设置 |
|---|---|
| 通用 | 开机自启、无声自动停止（30 秒 / 1 分钟 / 5 分钟 / 永不）、检查更新 |
| 翻译服务 | API Key（仅保存在本机）、连接测试、源/目标语言 |
| 字幕样式 | 样式、字号、背景不透明度，带实时预览 |

## 隐私

- API Key 仅保存在本机（UserDefaults），不上传任何第三方；
- 音频数据仅发送至你所配置的翻译服务商（火山引擎），静音期间不发送；
- 不采集、不上传屏幕画面，屏幕录制权限仅用于系统音频捕捉。
